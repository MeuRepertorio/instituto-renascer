# Instituto Renascer — Site institucional

Site institucional estático e responsivo do Instituto Renascer.

## Estrutura

- `index.html`: site completo em um único arquivo HTML, incluindo CSS e logotipo incorporado.
- `.nojekyll`: habilita a publicação direta de arquivos estáticos pelo GitHub Pages.

## Abrir e editar

Abra `index.html` em um navegador. Para editar conteúdo, layout e links, abra esse mesmo arquivo em um editor de texto ou código. As fontes Google Fonts dependem de conexão com a internet.

## Publicar pelo GitHub Pages

1. Crie um repositório público chamado `instituto-renascer`.
2. Envie os arquivos deste projeto para a raiz da branch `main`.
3. Abra **Settings > Pages** no repositório.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/(root)`, depois clique em **Save**.

O endereço padrão esperado é `https://meurepertorio.github.io/instituto-renascer/`, após a configuração e publicação.

## Observação

Site preservado conforme o HTML fornecido, sem mudanças de design ou conteúdo. Antes de divulgar, confirme dados institucionais, contatos e links apresentados na página.
